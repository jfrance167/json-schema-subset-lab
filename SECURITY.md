# Learning-lab security model

Use original synthetic values only. Trust boundaries are supplied exact native/UTF8 values, definition position interpretation, enum equality, result paths and physical file/stream delivery. Threats and fixed mitigations are specified in PLAN.md and exercised in tests: no custom hooks/cycles/coercion, logical budgets before support/evaluation, literal enum objects, exact bool/integer separation, absent/null presence, complete support and issue provenance, detached snapshots and physical ASCII cap before delivery.

No local/remote refs, schema regex evaluation, schema execution, installs, actual/private schemas, authorization or safety verdict. Fixed internal lexical regexes only check bounded profile/number spelling. Unknown features are unassessed validity, not silently ignored. Public render expects analyzer reports/trusted diagnostics. No arbitrary report-object admission contract.

File handling observes regular-file identity/length/metadata around reading and refuses existing/aliased outputs; it does not contain hostile concurrent filesystem races or guarantee atomic physical output. Concurrent native mutation is excluded. Runtime verification is Windows CPython3.13.7 only. Logical budgets do not promise hard time/RSS bounds, complete dialect compliance or maximal serialized-size proof.

ECC implementing-agent self-review and Bandit provide scoped evidence, not independent certification. No owned repository created; hosted CodeQL/security baseline/publication remain outside this local authorization. Do not put real/private inputs or sensitive operational material into fixtures, records or a future repository.
