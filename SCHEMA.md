# Frozen API and delivery contract

PLAN.md specifies envelope, all exact inclusive limits, grammar, evaluation/report ordering and fixed reasons. `analyze(envelope)` admits an exact native builtin envelope and returns `(report, exit_code)`. Known supported valid/invalid reports exit0/1; complete unsupported-feature report exit3. `LabError(ValueError)` with trusted fixed reason signals invalid input, invalid definition or resource limit. `Unsupported(LabError)` signals well-formed unknown outer schema/dialect after complete recognized grammar validation. `parse(raw)` accepts exact bytes and returns admitted decoded envelope; `analyze` remains the recognized grammar/support authority. `render(report)` returns compact sorted ASCII JSON plus exactly LF, or raises resource limit before delivery. Public callers must not supply real/private documents; concurrent mutation is excluded.

CLI `python -m schema_lab INPUT [--output FRESH_PATH]`. Fixed parser name schema-lab; help is argparse text with checked output/flush, exit0 only after successful delivery. Misuse uses exact ASCII LF stderr `{"reason":"invalid command arguments","status":"error"}\n`, exit2 and empty stdout. Unknown profile/dialect diagnostics use unsupported schema/unsupported dialect, status unsupported, exit3. Invalid native/encoded/generic/envelope data uses invalid input; malformed recognized schema shapes invalid definition; any required logical/report cap overflow resource limit, exit2. Observed read/write/flush/close/alias errors use I/O or output delivery failed, exit2. Controlled diagnostic sink failure also exit2; no uncontrolled destructor exit120. Known definition errors precede outer unsupported classification, which precedes feature reporting, which precedes instance evaluation. Report construction and ASCII cap precede fresh file creation/stdout.

No report mutation or hook execution; definition and instance snapshots detached from input and each other. Unsupported means unassessed validity (null), no partial issues. Complete issue reporting has no short-circuit after known failures. Keyword-position pointer rows and ordering are fixed in PLAN. Enum objects are literal values. Boolean additionalProperties operates on declared names, including declared children that fail.

Resource construction is independent of production code: 128 missing-member issues with two supplementary-codepoint ancestors; 3185 raw UTF8 bytes, 814207 full ASCII report bytes; generic counts saved in fixtures/resources.json. Reject actual report above262144 before physical delivery. Separate129-extra issue overflow and128-extra complete invalid counterpart. Logical work bounds are not hard RSS/time or physical transaction guarantees. Windows CPython3.13.7 initial verification target only.
