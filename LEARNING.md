# Learning

Required asks whether a key exists. A present null still exists. Properties evaluates present members and does not by itself forbid extras or require missing members. Object constraints have no effect on scalar instances, but their supplied definition syntax still needs checking.

Python bool inherits int and ordinary equality considers false equal to zero. Exact JSON kind checks prevent both errors. Enum objects contain literal data, even when their keys look like schema keywords.

Draft2020-12 enum nonempty/unique wording is SHOULD rather than MUST; candidate tests corroborate empty/duplicate admission. Explicit subset policies must not masquerade as complete dialect compliance.

Repeated long paths can amplify a small schema into a much larger report. The independent3185-byte input/814207-byte expected ASCII report demonstrates why physical output limits remain necessary.

The first actual CLI diagnostic comparisons exposed Windows stderr newline expansion. Configuring both exact interpreter TextIOWrapper streams for LF fixed diagnostics without relaxing expected bytes. A supplemental nested list example initially counted512 nodes exactly, so its failure expectation was wrong;511 elements plus two containers gives513 and crosses the unchanged512-node cap. Both initial failures remain in raw evidence.

The implementation-stage Ollama test suggestions were all rejected: they confused required presence with non-null and lacked supplied schemas. A successful transport is not a correct draft. Remote free guardrails then failed verification, so no remote inference occurred.

ECC found the need to separate enum resource admission from grammar validation: a malformed early type/required must not hide a later oversized enum member. A bounded preflight of recognizable enum positions now precedes grammar/support; the original failing regression and passing full checks remain evidence.
